# Mol Rush

A chemistry-themed browser clicker and synthesis game.

Start by clicking a simple hydrogen molecule, unlock new molecular feeds and synthesis skills, then combine representative molecules in the zoom reactor. The current prototype includes water, ammonia, methanol, urea, and aspirin routes with simplified ball-and-stick structures and short molecule notes.

Open `index.html` in a browser to play locally. The game is static and can be hosted from GitHub Pages or any static file server.
